{{ if not .Values.config.cacheUrl -}}

{{ if and .Values.config.cacheUrl (not (regexMatch "/[0-9]+$" .Values.config.cacheUrl)) -}}
WARNING: config.cacheUrl names no database index. Django's RedisCache.clear()
issues FLUSHDB and Janeway calls it whenever an editor saves settings, so on a
shared Redis/Valkey this will wipe whatever else is using index 0. Append an
unused index, e.g. .../6
{{ end -}}
